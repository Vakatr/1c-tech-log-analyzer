## EXCP — Исключительная ситуация

**Описание:** Возникает при ошибке в работе платформы или прикладного кода. Содержит текст исключения, контекст и стек вызовов.

**Поля:**

| Поле | Тип | Значение |
|------|-----|----------|
| Descr | String | Текст ошибки |
| Context | String | Контекст выполнения |
| Usr | String | Пользователь |

**Пример:**

```
13.09.2026 15:00:08.234
N=EXCP, p:processName=rphost, t:process=12346, Usr=Ivanov, AppID=1CV8, Descr=Ошибка при чтении документа: Ссылка не найдена
```

## DBMSSQL — Запрос к MS SQL Server

**Описание:** Выполнение SQL-запроса к базе данных Microsoft SQL Server. Регистрируется при превышении порога длительности (обычно 3 секунды).

**Поля:**

| Поле | Тип | Значение |
|------|-----|----------|
| sql | Text | Текст SQL-запроса |
| Rows | Int | Количество возвращённых строк |
| RowsAffected | Int | Количество изменённых строк |
| Duration | Int | Длительность в микросекундах |

**Пример:**

```
13.09.2026 15:00:02.456
N=DBMSSQL, p:processName=rphost, t:process=12345, Usr=Admin, AppID=1CV8, Duration=45000
```

## CALL — Вызов серверного метода

**Описание:** Регистрируется при вызове серверного метода. Позволяет измерять длительность выполнения процедур и функций на сервере.

**Поля:**

| Поле | Тип | Значение |
|------|-----|----------|
| Event | String | Имя метода |
| Duration | Int | Длительность в микросекундах |
| Memory | Int | Потребление памяти |

**Пример:**

```
13.09.2026 15:00:01.123
N=CALL, p:processName=rphost, t:process=12345, Usr=Admin, AppID=1CV8, Event=OpenForm, Duration=12500
```

## TLOCK — Ожидание блокировки

**Описание:** Регистрирует ожидание управляемой блокировки 1С, превысившее порог. Ключевой инструмент диагностики конфликтов.

**Поля:**

| Поле | Тип | Значение |
|------|-----|----------|
| Descr | String | Описание блокировки |
| Regions | Text | Регионы блокировки |
| Duration | Int | Время ожидания |
| WaitConnections | Int | Ожидающие соединения |

**Пример:**

```
13.09.2026 15:00:45.789
N=TLOCK, p:processName=rphost, Usr=Petrov, Duration=30000000, Descr=Превышение времени блокировки: 30 сек
```

## TDEADLOCK — Взаимоблокировка

**Описание:** Возникает, когда два или более соединений ждут ресурсы друг друга. СУБД выбирает жертву и разрывает её транзакцию.

**Поля:**

| Поле | Тип | Значение |
|------|-----|----------|
| Descr | String | Описание конфликта |
| Connections | Text | Участники |

**Пример:**

```
13.09.2026 16:00:03.400
N=TDEADLOCK, p:processName=rphost, Usr=Sidorova, Descr=Ошибка SQL: Deadlock detected
```
